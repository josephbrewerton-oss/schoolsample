💻 How does it work on Chromebooks?
School Chromebooks and modern PCs can run AI models right inside Chrome! When supported, Chrome downloads the model once to the device cache. After that, it generates customized practice questions and Socratic hints completely offline without needing school Wi-Fi or sending data to the cloud.
🔒Pupil Data & Device Consent (UK Children's Code / GDPR)

Status: Eco Mode (Default). Zero downloads and zero extra storage used. To protect device storage quotas and mobile data limits, model downloading is turned off until explicitly enabled.

📦 Model size: ~1.5 GB in Chrome cache  |  📶 Recommended only on unmetered school Wi-Fi  |  🔒 100% On-device
